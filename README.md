# QRいっき読み

画面内の QR コード・バーコードを **まとめて一括スキャン** できる Android アプリ。
画像からの一括抽出、QR の作成、履歴（宝箱）の管理まで、QR に関することはこれ1つで。

## 特徴

- **まとめてスキャン**：画面内のコードを一括検出（番号ピン＋リスト、重複は「×n」に集約）
- **画像から一括抽出**：写真やスクリーンショットの中のコードもまとめて読み取り
- **作る**：URL／Wi-Fi／連絡先／予定／場所／メール／SMS／電話／テキストの QR を作成、再編集・複製も可能
- **宝箱**：読み取り・作成の履歴を検索・お気に入り・フォルダで管理、PNG 保存・共有
- **端末内完結**：アカウントなし・広告なし。アプリに INTERNET 権限を持たせていないので、読み取った内容が外に出ることはありません

## 技術

- Kotlin / Jetpack Compose
- CameraX + ML Kit Barcode Scanning（全13形式対応）
- QR 生成は ZXing
- パッケージ名：`app.qrikkiyomi`

## 開発

```sh
./build.sh        # ビルド（共通ラッパー経由で直列化）
./run-tests.sh    # 交付前検証：単体テスト＋画面スクリーンショットテスト（golden 照合）
```

検証の詳細は [docs/VERIFICATION.md](docs/VERIFICATION.md)、仕様は [docs/MVP_SPEC.md](docs/MVP_SPEC.md) を参照。
