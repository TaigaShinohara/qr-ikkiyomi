# Phase 2 実装記録：連続スキャン／台帳モード＋CSV（2026-11-27、v0.5.0）

- 依頼の経緯：若者レビュー（docs/YOUTH_REVIEW_2026-11-27.md）の結論を受け、本人が「運営側の若者に絞って Phase 2 を進める」を選択（2026-11-27）。対象の再定義は MVP_SPEC §1／§3 に反映済み。
- 範囲：仕様 §2.3（連続スキャン／台帳モード）と FR-EXPORT-02 の台帳 CSV。読み取りレスキュー（FR-SCAN-06）は Phase 2 の残件として未着手。

## 画面と流れ

1. **開始**：スキャン画面のツールバー下に「連続スキャンを開始」（主ボタン）＋「台帳（N）」を常設（画像モードでは出さない）。開始すると新しい台帳（名前は開始日時「11/27 14:52 の台帳」）が作られ、連続モードに入る。
2. **連続読み**：結果シートは開かない（ピンもタップ無効）。新しいコードが画面に現れるたびに台帳へ自動追加され、短い振動1回で「記録した」が伝わる。一括検出もそのまま効く（複数同時出現は現れた順に全部入る）。
3. **SessionCounter**（ツールバー直下に固定）：件数（大）＋直近に読んだ内容＋重複警告バナー（出る時だけ）＋「一時停止／1件戻す／終了」。一時停止中は台帳への追加だけが止まり、カメラと出現判定は動き続ける（再開時に同じコードを二重に数えないため）。
4. **台帳リスト**（作業中）：読み取った順の番号つきで、新しいものが上。重複ペアの行には「重複」チップ（警告色）。行ごとの削除ボタンあり。
5. **終了**：「終了」を押すと台帳詳細へ着地する。過去の台帳は「台帳（N）」から一覧→詳細で開ける。未終了の台帳は「未終了」と示され、詳細から「この台帳で続ける」（再開）と「台帳を終了する」ができる。
6. **CSV**：台帳詳細の「CSVで書き出す」から共有シートへ（ファイル名 ledger_YYYYMMDD_HHmm.csv）。詳細では他に、名前の変更、行の個別削除、台帳の削除（確認あり）ができる。

## 決めたこと（仕様が黙っていた所）

- **重複**：行は分けて残す（棚卸しの数量＝読み取り回数）。2回目以降は振動2連パルス＋警告バナーで知らせる（設定「連続スキャンで重複を警告」、既定 ON でオフ可。§2.3 の「設定でオフ可」に対応）。一覧では重複ペアの両行に「重複」チップ、CSV では2行目以降の行に「重複」と入る。受付で読み済みに気づいたら「1件戻す」か行削除でその場で戻せる。
- **宝箱との関係**：台帳モードの読み取りは宝箱（履歴）に保存しない。台帳が作業の正本で、数百件の作業読み取りで個人の履歴を埋めないため。二重保存なし・欠落なし（台帳は読み取りごとに即保存され、アプリが落ちても未終了台帳として残る）。通常モードの自動保存（FR-SCAN-07）は台帳モード中は働かない。
- **保存方式**：台帳は宝箱とは別の端末内 JSON ファイル（ledgers.json）に、読み取りのたびに保存する。Phase 1 の保存方針（§11 の JSON 保存）と同じ流儀。
- **フィードバックは振動のみ**：検出音は出さない（§10「検出音は出さない」が正本）。新規＝短振動1回（設定「検出時に振動」に従う）、重複＝2連パルス（重複警告の設定に従う）。

## CSV の列構成

| 列 | 内容 |
| --- | --- |
| 日時 | 読み取り時刻（yyyy/MM/dd HH:mm:ss） |
| 形式 | QR_CODE / EAN_13 等の形式名 |
| 種別 | URL / Wi-Fi / テキスト等の種別ラベル |
| 内容 | 生データそのもの（作業記録のため伏字にしない） |
| 重複 | 2回目以降の同一内容の行だけ「重複」 |

- 読み取った順に1行ずつ。UTF-8（BOM 付き）＋ CRLF、カンマ・引用符・改行を含む内容は CSV 標準の引用で逃がす。FR-EXPORT-02 の履歴形（メモ／フォルダ列）は台帳の行に無いため、台帳形として上記に確定した（仕様 §8 に記録）。

## 実装の置き場所

- 純粋ロジック：`core/Ledger.kt`（台帳モデル、重複判定、JSON、CSV 生成）。単体テスト `LedgerTest` 9件。
- 保存：`core/Store.kt` の loadLedgers／saveLedgers＋設定 `warnOnLedgerDuplicate`。
- 画面：連続モードと SessionCounter は `ui/ScanScreen.kt`、台帳一覧・詳細は `ui/LedgerViews.kt`（新規パーツ LedgerSessionRow／LedgerRow／DuplicateChip を UI_CATALOG に登録）。
- 状態：台帳データは MainActivity が保持し全変更を即保存。連続モードの開閉状態は ScanState（タブ移動では消えない）。
