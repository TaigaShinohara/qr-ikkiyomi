# UIカタログ：QRいっき読み

- 最終更新：2026-11-24
- v0.4.4 での追いつき（2026-11-24、MINIMAL_REVIEW_2026-11-24.md の要判断 J-1 に対する本人の決定「生データは最初から畳む」）：ResultSheet（スキャンの結果シート）の生データブロックは、種別・内容を問わず**既定で折りたたむ**。「生データを表示」ボタン（全種別に常設し、折りたたみ状態を読み上げにも伝える）でのみ展開し、展開時は完全な生データを表示する（Wi-Fi では伏字解除を兼ねる。伏字が既定である点は R2-3 から不変で、畳んだ状態では生データ自体が画面に出ない）。v0.4.3 の「見出しと完全一致する生データブロックは出さない」条件分岐は、この一律折りたたみに置き換えた。宝箱詳細の生データ表示は対象外で従来どおり（見出しと一致しない限り表示し、Wi-Fi パスワードは伏字が既定）。実装は ResultContent の `collapseRawByDefault` 引数で出し分ける（結果シート＝true／宝箱詳細＝false）。結果シートの他の要素（種別フィールド・警告・推奨アクション・コピー／共有）は不変で、コピーは畳んだままでも使える。
- v0.4.3 での追いつき（2026-11-24、minimal_information_design による情報量見直し。詳細は `docs/MINIMAL_REVIEW_2026-11-24.md`）：ResultSheet は、見出し（要約）と完全一致する生データブロックを表示しない（差分がある場合のみ出す）。URL 見出し上の「開く前に確認」ラベルを廃止。Wi-Fi の確認行は「暗号化: …」のみとし（SSID は見出しが正本）、接続方式の説明を2事実に短縮。スキャン画面の「全部を履歴に保存」ボタンは、自動保存（FR-SCAN-07、既定 ON）が有効な間は表示しない（押しても全件保存済みになるだけのため）。画像スキャン成功時の件数注記を廃止し、件数の正本を結果見出しに一本化。画像モードではカメラ前提の空状態文を出さない。作る画面は下部のエラー要約を廃止（項目直下のエラーが正本）、詳細設定の再保証文と GEO ヒントの2文目を削除。宝箱は検索ラベルを「検索」に短縮し、メモ欄の見出しを入力欄ラベルに一本化。設定画面は「設定」見出しを廃止（選択中タブが正本）し、トグル説明を非自明な差分だけに圧縮、プライバシー説明の正本を「このアプリについて」に一本化。パーツの役割・寸法・色に変更はない。
- v0.4.0 での追いつき（2026-11-15、UX見直し第2回）：DetectionPin は選択中（開いている結果）を白リングで示し、ピン自体に「番号＋種別＋要約」の読み上げ名を持つ（R2-9／P2-10）。FolderChipRow のお気に入りチップは、お気に入りが1件も無いときは出さない（P2-12、`hasFavorites` 引数）。HistoryRow のお気に入り星は見た目28dpのままタッチ領域48dp（P2-10）。ResultSheet／HistoryRow／宝箱詳細の生データ表示は Wi-Fi パスワード伏字が既定（R2-3）。
- アート方針：`docs/ART_DIRECTION.md` の版 1.1 に準拠
- 状態：Phase 1（v0.1.0）実装済みのパーツは正本の場所を実パスへ更新済み（2026-11-14）。SessionCounter のみ Phase 2 のため設計のみ。
- v0.2.0 での追いつき（2026-11-14）：TypeChip がカタログどおり「アイコン＋言葉」になり、FolderChipRow は「フォルダが無く、お気に入りも無い時は行自体を出さない」を実装側でも満たした（呼び出し側で出し分け）。WarningBanner はテーマ連動色へ変更。パーツの役割・狙いの記述自体に変更はない。
- v0.3.0 デザイン整備での変更（2026-11-14、詳細は `docs/DESIGN_REVIEW_2026-11-14.md`）：新規パーツ **SecondaryActionButton** を登録し、全画面の補助ボタンをこれへ統一した（従来の素の OutlinedButton の散在を解消）。PrimaryActionButton の寸法を 52dp／角丸トークンへ固定。TypeChip・MiniChip の角丸を shapes.small へ、WarningBanner の色を QrRoleColors トークンへ、QrPreview の白い面に角丸トークンを適用。EmptyGuide は中央寄せ組版を既定とし、宝箱の完全な空状態では画面中央に置く。ScanToolbar はフラット化＋ラベル付きに改定。**AppIcon** を番外パーツとして登録。

## パーツ詳細

### DetectionPin

- 役割：カメラ映像上で、検出したコードの位置と結果リストの対応を示す。
- 使う場面：スキャン画面（一括検出時）。
- 使わない場面：1個だけを大きく読む拡大表示、宝箱。
- 状態：通常（番号表示）／選択中（強調）／重複あり（×n 併記）。
- 狙い：「全部読めた」が目で数えられ、合わせ直しが不要だと即分かる。
- アート方針との対応：色は検出の合図にだけ使う（§3）。ピンは単色＋番号で統一。
- バリエーション：番号と重複数のみ変更可。色・形の個別変更は不可。

### ResultSheet

- 役割：読み取り結果の表示と、次の行動の実行をこのシート内で完結させる。
- 使う場面：スキャン直後、宝箱から履歴を開いた時。
- 使わない場面：連続モードの最中（邪魔になるため、件数のみの表示にする）。
- 状態：通常／複数結果（リスト＋選択で詳細）／警告あり（WarningBanner 併置）。
- 狙い：主役は「中身の要約」と PrimaryActionButton 1つ。他は全部補助に降格。
- アート方針との対応：1画面1メッセージ、階層3段まで（§5）。
- バリエーション：種別によって推奨ボタンの文言と補助行動が変わることは可。

### PrimaryActionButton

- 役割：その場面の推奨行動を1つだけ、最も大きく押させる。
- 使う場面：ResultSheet、作成完了、空状態の案内、カメラ許可の案内。
- 使わない場面：破壊的操作（削除）は使わない（通常ボタン＋確認にする）。
- 状態：通常／押下／無効（入力不足時）。
- 狙い：迷う時間をゼロにする。ボタンが1つしか目立たないことが機能そのもの。
- アート方針との対応：主色はこのボタンと検出の合図だけ（§3）。
- 寸法（v0.3.0 で固定）：高さ 52dp、角丸は shapes.medium（12dp）、全幅。文言は titleMedium。
- バリエーション：文言とアイコンのみ変更可。画面内に2つ並べることは不可。

### SecondaryActionButton（v0.3.0 新規）

- 役割：推奨以外の行動（保存・共有・複製・バックアップ等）を、全画面で寸分違わぬ形で置く。
- 使う場面：ResultSheet の補助行動、作る画面の PNG 保存／共有、宝箱詳細の補助・管理、設定のデータ操作。
- 使わない場面：推奨行動（PrimaryActionButton の領分）、シート内の削除（TextButton＋確認ダイアログのまま）、チップ型の選択（FilterChip の領分）。
- 状態：通常／押下／無効／danger（破壊的操作用：枠と文字がエラー色）。
- 狙い：ボタン同士の形の差で迷わせない。並べた時に潰れたり折り返したりしない（幅は列に揃えるか、FlowRow で流す）ことが、v0.2.0 の設定画面の崩れを繰り返さないための条件。
- アート方針との対応：形の言語（§4）のボタン寸法ルールの実装そのもの。
- 寸法：高さ 48dp、角丸 shapes.medium（12dp）、枠線 1dp、文言は labelLarge・1行固定。
- バリエーション：文言、danger の有無、幅（全幅／等分／自然幅）のみ。

### TypeChip

- 役割：URL／Wi-Fi／連絡先などの種別を、アイコン＋短い言葉で示す。
- 使う場面：ResultSheet、HistoryRow、結果リスト。
- 使わない場面：作成フォームの中（見出しで足りる）。
- 状態：通常のみ。
- 狙い：本文を読まずに「何のコードか」が分かる。
- アート方針との対応：色でなくアイコン形状の区別を優先（§3）。

### ScanToolbar

- 役割：懐中電灯、ズーム、画像から読む、連続モード切替を、カメラの邪魔にならない位置に置く。
- 使う場面：スキャン画面の下部。
- 使わない場面：他画面。
- 状態：通常／オン状態（懐中電灯点灯中はアイコンが主色になる）。
- 狙い：道具は端に寄せ、カメラ映像が主役であり続ける。
- アート方針との対応：装飾を排し主役を大きく（§2）。
- v0.3.0 の形：面はフラット（トーンで浮かせず、上端に最も弱い線1本）。両端の道具は同じ幅（52dp）＋小さなラベル（ライト／画像）付き。ズームスライダーはテーマ色（つまみ・有効トラック＝主色、無効トラック＝補助コンテナ色）。
- バリエーション：ボタンの増減は可。中央に大きなボタンを置く変更は不可（シャッターは無い設計）。

### HistoryRow

- 役割：宝箱の一覧1件。種類・要約・日時・お気に入りを1行で示す。
- 使う場面：宝箱（履歴／保存済み／フォルダ内）。
- 使わない場面：スキャン結果リスト（ResultSheet 側のリストを使う）。
- 状態：通常／お気に入り／選択中（複数選択削除時）。
- 狙い：探すのではなく見つかる。スキャンで再利用まで進める。
- アート方針との対応：道具らしい密度を許すが1行の役割は固定（§5）。
- バリエーション：お気に入り印とフォルダ名の表示有無のみ。

### QrPreview

- 役割：生成した QR を、読み取り精度を守る条件で表示する。
- 使う場面：作る画面のプレビュー、作成完了、宝箱の詳細。
- 使わない場面：一覧のサムネイル（小さい再描画で代替し、形だけ示す）。
- 状態：通常（白背景＋黒）／デザイン編集後（警告併置があり得る）／読み取り不可警告時。
- 狙い：見た目より「相手が読める」ことを守る砦。
- アート方針との対応：QR 表示の白背景固定（§3）は精度のための例外として明示。
- バリエーション：サイズ変更可。背景を透過にする変更は不可。

### TypePickerGrid

- 役割：作る QR の種類を、アイコン＋名前で選ばせる。
- 使う場面：作る画面の先頭。
- 使わない場面：再編集時（種類は固定で開く）。
- 状態：通常のみ。
- 狙い：8種（Phase 3 で追加）の中から探す時間を短くする。
- アート方針との対応：色は使わず、アイコンと名前で区別（§3）。
- バリエーション：種類の追加は可。広告枠やおすすめ枠を差し込むことは不可。

### SessionCounter

- 役割：連続モード中の合計件数、重複警告、直近に読んだ内容を常時示す。
- 使う場面：連続スキャンモード。
- 使わない場面：通常スキャン。
- 状態：通常／重複警告（振動と連動）／一時停止。
- 狙い：画面を見続けなくても作業が進む。件数が主役。
- アート方針との対応：平常時は静か、警告時だけ強く（§2）。
- バリエーション：表示位置は下部固定。

### WarningBanner

- 役割：安全上の注意（短縮 URL、IDN、QR の密度過多など）を、行動の前に示す。
- 使う場面：ResultSheet、作る画面。
- 使わない場面：注意が無い場面（常時表示しない）。
- 状態：注意（黄系の役割色）／強い注意（赤系は本当に危険な兆候の時だけ）。
- 狙い：いつも出ていないからこそ、目に留まる。
- アート方針との対応：平常時は静か、警告だけ強く（§2）。
- バリエーション：文言のみ変更可。閉じるボタンを付けて消せるようにはしない（その場限りの注意のため）。

### EmptyGuide

- 役割：空状態（履歴ゼロ、フォルダが空など）で、一文と次の行動1つだけを示す。
- 使う場面：宝箱、検索結果ゼロ。
- 使わない場面：読み込み中（スケルトンやスピナー側の領分）。
- 状態：通常のみ。
- 狙い：行き止まりにしない。イラストは使わない（アート方針 §4）。
- アート方針との対応：イラストを使わない決定に準拠。
- 組版（v0.3.0）：文は中央寄せ。画面全体が空の状態（宝箱が空）では画面中央に置き、検索結果ゼロなど部分的な空ではその場に置く。

### FolderChipRow

- 役割：宝箱をフォルダで絞り込む横並びのチップ列。
- 使う場面：宝箱の上部。
- 使わない場面：フォルダが1つも無い時（行自体を出さない）。
- 状態：通常／選択中。
- 狙い：階層を深くせず、1タップで絞れる。
- アート方針との対応：選択肢を増やさない（§5）。増えすぎたら検索へ寄せる。
- バリエーション：並び順は名前順／最近使った順のどちらか。

### AppIcon（番外：ランチャーアイコン）

- 役割：ホーム画面で「QRを読む道具だ」と1秒で伝える。
- 使う場面：ランチャー、ストア掲載。
- 状態：単一（adaptive icon：藍地＋白抜き前景）。
- 狙い：アプリを開く前から「速い・正確・静か」の世界を始める。QR のファインダーパターンを正しい比率（7：4.5：2.5相当）で描き、データモジュールを少しだけ添える。文字・飾りは入れない。
- アート方針との対応：主色の藍（地色はトークンの深い藍 #0E2A4E）と形の言語（角の処理）に準拠。v0.2.0 までは既定に近い青地＋崩れたファインダー比のベクターだったため、v0.3.0 で描き直した。
- バリエーション：地色はトークン変更時に追随する。前景の構図変更はデザイン記録に理由を残すこと。
